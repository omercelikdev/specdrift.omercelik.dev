## It never calls an LLM. LLMs call it.

AI-generated changes decay exactly where no tool is looking: between artifacts. A model adds a feature
flag to the manifest and forgets the package. It wires a call and forgets to declare it. It regenerates
an OpenAPI document and never commits it. Each artifact is individually valid; together they lie.

specdrift is deliberately boring. Same inputs, byte-identical report. No network, no clocks in the
output, no model in the loop — so an agent can trust the answer, and so can your CI.

```bash
specdrift validate .platform/manifest.yaml --schema manifest.schema.json --rules rules.yaml
specdrift drift --repo .
```

```
ERROR SPEC0101 at features.distributedCaching.redis.connectionName:
  features.distributedCaching.levels includes 'l2' but redis.connectionName is missing
  — name the connection the cache should use.
ERROR SPEC0201 at features.outbox:
  the manifest enables this feature but no project references 'Platform.Messaging'
  — the app does not do what the manifest says.
```

## Reports, never auto-fixes

Drift detection is **textual by design**, and says so out loud: it scans project files for package
references and source files for wiring calls. Cheap, fast, and honest about what it is. Roslyn-grade
analysis belongs in analyzers that run inside your compilation — not in a lint pass over a repository.

So specdrift tells you what diverged and where. It never edits your code to make the report go away.
